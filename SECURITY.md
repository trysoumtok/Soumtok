# Security Policy

## Reporting a vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Email **security@soumtok.com** with:

- A description of the issue and affected components (Studio, Desktop, API)
- Steps to reproduce
- Impact assessment, if known

We aim to acknowledge reports within **3 business days** and will coordinate disclosure with you.

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest `main` | Yes |
| Desktop 0.1.x | Yes |
| Older tags | Best effort |

## Scope

In scope: Soumtok Studio, Soumtok Desktop, and the API server in this repository.

Out of scope: third-party extensions, MCP connectors you install separately, and misconfiguration of your own `.env` secrets.
